# Rastgele Varoluşsal Kriz Üretici

## Giriş

Bu proje, insanlığın en temel sorununa çözüm üretmek amacıyla başlatılmıştır: **Hayatın anlamsızlığını unutmak.**

Rastgele Varoluşsal Kriz Üretici, kullanıcının zihnine anlık ve bilimsel olarak doğrulanmış varoluşsal krizler enjekte eder. Her çalıştırıldığında, evrenin soğuk gerçeklerini hatırlatarak motivasyonunuzu sıfıra indirir. Bu, aslında bir özelliktir.

## Özellikler

- **%100 Bilimsel**: Termodinamik yasaları, kuantum rastgeleliği ve ısı ölümü referansları içerir.
- **Anında Etki**: Tek bir çalıştırma ile gününüzü mahvedebilir.
- **Patent Bekliyor**: VK-2026-ANLAMSIZ numaralı patent başvurusu yapılmıştır.
- **Açık Kaynak**: Çünkü anlam zaten yok, neden kodu saklayalım?

## Kurulum

```bash
git clone https://github.com/Tentivory/rastgele-varolussal-kriz-ureteci.git
cd rastgele-varolussal-kriz-ureteci
python3 kriz_ureteci.py
```

Başka hiçbir şey yapmanıza gerek yok. Zaten hiçbir şeyin anlamı yok.

## Kullanım

Programı çalıştırdığınızda, size özel olarak üretilmiş bir varoluşsal kriz sunulur. Bu kriz, hayatınızı sorgulamanız için tasarlanmıştır. İtiraz etmeyin. Evren dinlemiyor.
